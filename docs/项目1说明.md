一、 作业目标 
本实验要求综合利用本学期所学的 Qt 核心知识，实现一个具备特殊输入方式的“简易财务计算器”。通过本实验，学生应达到以下目标：

掌握 UI 设计与资源管理：熟练使用 Qt Designer（.ui 文件）进行界面布局，理解 UI 编译过程；掌握 Qt 资源系统（.qrc）和 QSS 样式表美化界面。 

深化信号与槽机制：熟练运用信号与槽实现按钮交互，并掌握跨窗口（对话框与主窗口）及控件间的通信。 

掌握事件驱动编程：深入理解 Qt 事件机制，熟练运用虚函数重写（如鼠标事件、绘制事件）或事件过滤器实现自定义交互逻辑。 

培养工程查阅能力：养成在开发过程中主动查阅 Qt 官方帮助文档（Qt Assistant）和数据手册的习惯。 

二、 功能需求 
2.1 基础计算功能（必做） 
四则运算：支持加、减、乘、除。 

财务计算

单利/复利计算 

显示与反馈：提供显示区域，实时展示输入表达式与计算结果；具备清除（C）和退格（←）功能。 

错误处理：遇到除零、格式错误等情况时，通过状态栏或 QMessageBox 给出提示，保证程序不崩溃。 

2.2 输入方式 
鼠标点击/拖拽输入（基于鼠标事件重写） 

通过重写鼠标事件来模拟拖拽体验。

界面上提供一组“数字/运算符标签（QLabel）”或“按钮”。 

用户按下鼠标选中某个数字，移动鼠标时会有一个“跟随的阴影或文本”跟随光标。 

当用户释放鼠标时，如果光标位于“显示/输入区域”上方，则将对应的数字/符号追加到计算表达式中。 

2.3 界面与交互要求 
布局管理器：必须使用布局管理器（Layouts）进行界面排版，禁止纯坐标硬编码，保证窗口缩放时控件自适应。 

QSS 美化：使用 QSS 为计算器按钮、显示框、手写画板设置自定义样式（如悬停变色、圆角边框等）。 

资源文件：将用到的图标、背景图等通过 Qt 资源系统（.qrc）引入项目。 

窗口通信（必做项）：实现一个“财务参数设置”对话框（如设置利率、年限）。要求通过信号与槽将对话框中的参数传递给主窗口，考察窗口间通信能力。 

三、 技术要求与约束 
开发环境：C++、Qt 6（Qt Creator）。 

UI 文件：所有界面必须使用 .ui 文件设计。

架构分离：UI 显示（View）与计算逻辑（Model）需适度分离，不建议将所有代码堆砌在 MainWindow 中。 

事件处理：必须在代码中体现虚函数重写或事件过滤器的正确使用，并在实验报告中说明为何选择该方式。 

四、 提交要求 
提交完整的 Qt 项目文件夹（包含 .pro、.h、.cpp、.ui、.qrc 等）。 

确保项目可正常编译运行，代码需包含必要的中文注释（特别是信号与槽连接、事件处理函数部分）。
